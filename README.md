# 📚 자습실 출석 체크 시스템

학생들의 자습 현황을 간편하게 모바일에서 출석체크할 수 있는 웹 애플리케이션입니다.

## 🌟 주요 기능

### 👨‍🏫 감독 선생님 기능
- **학년별 구분**: 1, 2, 3학년별로 구분하여 관리
- **자습공간 선택**: 각 학년의 자습공간 선택 가능
- **간편한 출석 체크**: 
  - 학생 카드를 탭하여 출석 상태 변경
  - 출석 → 결석 → 공결 → 병결 순환
  - 일괄 출석 버튼으로 한 번에 전체 출석 처리
- **1차/2차 출석**: 하루에 두 차례 출석 체크 가능
- **시각적 표시**: 색상으로 한눈에 출석 현황 파악
  - 🟢 출석: 초록색
  - 🔴 결석: 빨간색
  - 🟠 공결: 주황색
  - 🟣 병결: 보라색

### 👨‍💼 관리자 기능
- **통계 조회**: 기간별, 학년별, 자습공간별 출석 통계
- **결석 횟수 확인**: 학생별 결석 횟수 및 결석률 표시
- **엑셀 다운로드**: 출석 현황을 엑셀 파일로 다운로드
- **사전 결석 관리**: 공결, 병결 등 사전에 미리 체크 가능

### 📱 모바일 최적화
- 반응형 디자인으로 모바일에서 편리하게 사용
- 한 페이지에 많은 학생 표시로 빠른 체크
- 터치 친화적인 UI

## 🏗️ 기술 스택

- **Frontend**: React + Vite
- **Backend**: Node.js + Express
- **Data**: JSON 파일 기반 저장
- **Export**: XLSX (엑셀 다운로드)

## 🚀 설치 및 실행

### 1. 백엔드 서버 시작

```bash
cd backend
npm install
npm start
```

서버가 http://localhost:3001 에서 실행됩니다.

### 2. 프론트엔드 시작

```bash
cd frontend
npm install
npm run dev
```

프론트엔드가 http://localhost:3000 에서 실행됩니다.

## 📱 사용 방법

### 출석 체크하기

1. **홈 화면**에서 "출석 체크" 선택
2. **학년 선택** (1, 2, 3학년)
3. **자습공간 선택**
4. **날짜와 차수 선택** (1차 또는 2차)
5. **학생 카드 터치**로 출석 상태 변경
   - 한 번 터치: 출석 → 결석
   - 두 번 터치: 결석 → 공결
   - 세 번 터치: 공결 → 병결
   - 네 번 터치: 병결 → 출석
6. **일괄 출석 버튼**으로 전체 출석 처리 가능
7. **저장 버튼**으로 출석 데이터 저장

### 통계 확인하기

1. **홈 화면**에서 "관리자" 선택
2. **기간 설정** (시작일 ~ 종료일)
3. **학년 선택** (선택사항)
4. **조회 버튼** 클릭
5. 학생별 출석 통계 확인
6. **엑셀 다운로드** 버튼으로 데이터 다운로드

## 🎨 디자인 특징

- **깔끔하고 세련된 디자인**: 보라색 그라데이션 배경
- **직관적인 색상 코딩**: 출석 상태를 색상으로 즉시 파악
- **카드 기반 UI**: 각 학생을 카드로 표시하여 시각적으로 명확
- **반응형 디자인**: 모바일, 태블릿, 데스크톱 모두 지원

## 🔒 데이터 관리

- 모든 출석 데이터는 `backend/data/` 폴더에 JSON 형식으로 저장
- 누적 데이터로 보관되어 통계 조회 가능
- 날짜별, 세션별, 자습공간별로 구분하여 저장

## 🎯 주요 특징

✅ **간편한 조작**: 터치 한 번으로 출석 상태 변경

✅ **일괄 처리**: 전체 출석 버튼으로 대부분의 학생 한 번에 처리  
✅ **실시간 저장**: 출석 데이터 즉시 저장 및 조회  
✅ **통계 기능**: 학생별 결석 횟수 및 결석률 확인

## 📝 API 엔드포인트

- `GET /api/grades` - 학년별 구조 조회
- `GET /api/grades/:grade/rooms` - 학년별 자습공간 목록
- `GET /api/students` - 학생 목록 조회
- `POST /api/attendance` - 출석 데이터 저장
- `GET /api/attendance` - 출석 데이터 조회
- `POST /api/pre-absence` - 사전 결석 등록
- `GET /api/pre-absence` - 사전 결석 조회
- `DELETE /api/pre-absence/:id` - 사전 결석 삭제
- `GET /api/statistics` - 통계 조회
- `GET /api/export/excel` - 엑셀 다운로드

## 🐛 문제 해결

### 백엔드 서버가 시작되지 않는 경우
- `students_data.csv` 파일이 올바른 위치에 있는지 확인
- Node.js 버전 확인 (v14 이상 권장)

### 프론트엔드에서 데이터가 로드되지 않는 경우
- 백엔드 서버가 실행 중인지 확인
- 브라우저 콘솔에서 에러 메시지 확인
