# KSA 모바일 면학시스템 v2.0 사용 가이드

## 🎯 v2.0의 핵심 특징

### v1.0과 100% 동일한 기능
- ✅ **모든 UI/UX 그대로**: 버튼, 레이아웃, 색상 모두 동일
- ✅ **좌석 배치도 6개**: 3학년 창조관/본관/형설관 EOZ 전부 포함
- ✅ **390명 학생 데이터**: 전체 학생 정보 내장
- ✅ **3개 학년 × 24개 공간**: 모든 자습실 지원
- ✅ **통계 대시보드**: 실시간 출석률 확인
- ✅ **날짜/차수 관리**: 1차/2차 면학 구분

### v1.0과 다른 점
- 🔒 **서버 불필요**: HTML 파일만 열면 즉시 사용
- 💾 **localStorage 저장**: 브라우저에 데이터 자동 저장
- 📤 **CSV 내보내기**: 엑셀로 결과 제출
- 🌐 **인터넷 불필요**: 완전 오프라인 작동

## 📱 교사용 가이드

### 1단계: 파일 받기
- 파일: `attendance.html` (376KB)
- 다운로드: 이메일/USB/공유폴더

### 2단계: 파일 열기
```
방법 1: 더블클릭
   → 기본 브라우저에서 자동 실행

방법 2: 브라우저에서 직접 열기
   → Chrome/Edge 실행 → Ctrl+O → 파일 선택
```

### 3단계: 출석 체크
1. **초기 설정**
   - 날짜 선택 (오늘 날짜 자동 입력됨)
   - 차수 선택 (1차/2차)
   - 담당자 이름 입력
   - 학년 선택 (1/2/3학년)
   - 자습 공간 선택

2. **출석 체크 방법**
   
   **리스트 모드** (기본)
   - 학생 카드를 탭하면 출석/결석 토글
   - 초록색 = 출석 ✅
   - 빨간색 = 결석 ❌
   - 노란색 = 공결 📋 (변경 불가)

   **좌석표 모드** (3학년 일부 공간)
   - 좌석을 탭하면 색상 변경
   - 실제 좌석 배치대로 표시
   - 터치 친화적 큰 버튼

3. **데이터 자동 저장**
   - 매번 탭할 때마다 자동으로 브라우저에 저장
   - 실수로 창을 닫아도 데이터 유지
   - 다시 열면 이어서 작업 가능

### 4단계: 결과 제출
1. **CSV 내보내기 버튼** 클릭 (오른쪽 하단)
2. `KSA출석체크_전체_2025-11-06.csv` 파일 다운로드
3. 이메일에 첨부하여 담당자에게 전송

## 👨‍💼 담당자용 가이드

### 공결 학생 관리

**방법 1: 관리자 모드 사용**
1. 메인 화면 → "관리자" 탭
2. "공결 사전등록" 선택
3. 학번/이름 입력
4. 날짜 범위 선택
5. "등록" 버튼

**방법 2: JSON 파일 배포** (고급)
1. 공결 학생 JSON 파일 생성
   ```json
   {
     "2025-11-06": [
       {"studentId": "24-006", "studentName": "고태경", "reason": "병원"},
       {"studentId": "24-015", "studentName": "김시현", "reason": "대회"}
     ]
   }
   ```
2. 교사들에게 배포
3. 교사가 "데이터 불러오기"로 import

### 교사 제출 CSV 취합

1. **CSV 파일 수집**
   - 각 교사로부터 CSV 파일 이메일 수신
   - 하나의 폴더에 모두 저장

2. **Excel에서 통합**
   ```
   Excel 실행 → 데이터 탭 → "파일에서" → "CSV"
   → 모든 CSV 선택 → 병합
   ```

3. **통계 분석**
   - 피벗 테이블로 출석률 계산
   - 학년별/공간별 집계
   - 결석자 명단 추출

## 🔧 고급 기능

### localStorage 데이터 관리

**데이터 보기** (개발자 콘솔)
```javascript
// F12 키 → Console 탭
const data = localStorage.getItem('ksa_attendance_offline');
console.log(JSON.parse(data));
```

**데이터 백업**
```javascript
// 전체 데이터 JSON으로 다운로드
const data = localStorage.getItem('ksa_attendance_offline');
const blob = new Blob([data], { type: 'application/json' });
const url = URL.createObjectURL(blob);
const a = document.createElement('a');
a.href = url;
a.download = 'ksa_backup_' + new Date().toISOString() + '.json';
a.click();
```

**데이터 복원**
```javascript
// JSON 파일에서 데이터 불러오기
// (파일 → 텍스트 복사 → 아래 실행)
const jsonData = '...'; // 복사한 JSON 붙여넣기
localStorage.setItem('ksa_attendance_offline', jsonData);
location.reload(); // 페이지 새로고침
```

**데이터 초기화** (주의!)
```javascript
// 모든 데이터 삭제
localStorage.removeItem('ksa_attendance_offline');
alert('데이터가 초기화되었습니다.');
location.reload();
```

## 💡 사용 팁

### 빠른 출석 체크
1. 리스트는 학번순으로 정렬됨
2. 탭 → 탭 → 탭 연속 터치로 빠르게 진행
3. 결석자만 표시하면 더 빠름

### 실수 수정
- 잘못 터치하면 → 다시 터치하면 원래대로
- 2-state 토글이므로 누르면 바뀜

### 여러 공간 동시 관리
- 각 공간별로 새 탭 열기
- 탭마다 독립된 localStorage 저장

### 모바일에서 사용
- 핀치 줌 비활성화됨 (실수 방지)
- 터치 친화적 큰 버튼
- 세로 모드 최적화

## ⚠️ 주의사항

### 데이터 손실 방지
1. **주기적 백업**: 매주 CSV 내보내기
2. **브라우저 데이터 삭제 주의**: "쿠키 및 사이트 데이터 지우기" 하면 출석 데이터도 삭제됨
3. **복수 백업**: 여러 날짜의 CSV 파일 보관

### 브라우저 호환성
- ✅ Chrome 90+ (권장)
- ✅ Edge 90+
- ✅ Firefox 88+
- ✅ Safari 14+
- ❌ Internet Explorer (지원 안 함)

### 저장 용량
- localStorage 기본 제한: 5-10MB
- 출석 데이터 1건: 약 200 bytes
- 예상 사용량: 1개월 사용 시 약 500KB

## 🆘 문제 해결

### Q: 화면이 안 보여요
A: F5 키로 새로고침하거나, 다른 브라우저에서 시도

### Q: 데이터가 사라졌어요
A: 
1. 브라우저 캐시를 삭제했는지 확인
2. 시크릿 모드로 열었는지 확인 (시크릿 모드는 데이터 저장 안 됨)
3. 백업 CSV 파일에서 복원

### Q: CSV 파일이 깨져서 보여요
A:
1. Excel에서 "데이터 → 텍스트에서" 메뉴 사용
2. 인코딩을 "UTF-8"로 선택
3. 구분 기호를 "쉼표"로 선택

### Q: 공결 학생이 안 보여요
A:
1. 관리자 모드에서 공결 등록 확인
2. 날짜가 맞는지 확인
3. 학년/공간이 일치하는지 확인
