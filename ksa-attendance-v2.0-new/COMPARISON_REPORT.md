### 2. 배포 프로세스

#### v1.0 배포 단계 (15단계)
```bash
# 1. 서버 준비
$ ssh user@school-server

# 2. Node.js 설치
$ curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
$ sudo apt-get install -y nodejs

# 3. 프로젝트 복사
$ scp -r ksa-attendance-system user@school-server:/opt/

# 4. 백엔드 설정
$ cd /opt/ksa-attendance-system/backend
$ npm install  # 5-10분 소요
$ npm run start &

# 5. 프론트엔드 설정
$ cd ../frontend
$ npm install  # 5-10분 소요
$ npm run build
$ npm run preview &

# 6. 방화벽 설정
$ sudo ufw allow 3000
$ sudo ufw allow 5173

# 7. 프로세스 관리자 설정 (PM2)
$ npm install -g pm2
$ pm2 start backend/server.js
$ pm2 start frontend/npm --name "frontend" -- run preview
$ pm2 startup
$ pm2 save

# 8. 테스트
$ curl http://localhost:3000/api/students
$ curl http://localhost:5173

# 총 소요 시간: 2-4시간
# 기술 수준: 중급 이상
```

#### v2.0 배포 단계 (2단계)
```bash
# 1. 파일 복사
복사: ksa-attendance-v2.0-new/teacher/attendance.html

# 2. 더블클릭
더블클릭하여 브라우저에서 열기

# 총 소요 시간: 5초
# 기술 수준: 초급 (컴퓨터 사용법만 알면 됨)
```
