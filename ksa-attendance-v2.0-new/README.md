# KSA 모바일 면학시스템 v2.0 (완전 오프라인)

## 개요
v1.0의 모든 기능을 그대로 유지하면서 서버 없이 작동하는 완전 오프라인 버전입니다.

## v1.0 기능 100% 이식

### ✅ 완전히 이식된 기능
- 🏫 **3개 학년별 관리** (1학년, 2학년, 3학년)
- 📍 **24개 자습 공간** 지원
- 🪑 **좌석 배치도 6개 공간** (3학년 창조관/본관/형설관 EOZ)
- 📊 **실시간 출석 통계** (전체/출석/결석/공결)
- 👥 **390명 학생 관리**
- 📅 **날짜/차수별 출석 관리**
- 👨‍🏫 **담당자 이름 기록**
- 🔄 **출석/결석 2-state 토글**
- 🚫 **공결 학생 자동 보호**
- 📱 **모바일 터치 최적화**

### 🔄 변경된 부분
- ❌ **서버 API** → ✅ **localStorage**
- ❌ **실시간 동기화** → ✅ **CSV 파일 제출**
- ❌ **중앙 DB** → ✅ **브라우저 저장소**

## 사용 방법

### 교사용 (attendance.html)

1. **파일 열기**
   - 더블클릭 또는 브라우저에서 열기
   - 인터넷 연결 불필요

2. **출석 체크**
   - 날짜/차수/담당자 입력
   - 학년 선택 → 공간 선택
   - 좌석표 또는 리스트에서 출석 체크
   - 자동 저장됨 (localStorage)

3. **결과 제출**
   - "결과 내보내기" 버튼
   - CSV 파일 다운로드
   - 이메일로 담당자에게 전송

### 담당자용 (data_manager.html)

1. **공결 학생 관리**
   - 날짜별 공결 학생 등록
   - Excel 붙여넣기 지원
   - 데이터 JSON 파일로 내보내기

2. **통계 확인**
   - 교사들이 제출한 CSV 파일 불러오기
   - 기간별 출석 통계 확인
   - Excel로 내보내기

## 데이터 흐름

### 출석 체크 흐름
```
1. 교사가 attendance.html 실행
2. 오늘 날짜 선택
3. 학년/공간 선택
4. 출석 체크 (localStorage 자동 저장)
5. CSV 내보내기
6. 이메일로 담당자에게 전송
```

### 데이터 관리 흐름
```
1. 담당자가 data_manager.html 실행
2. 공결 학생 정보 입력
3. JSON 파일로 내보내기
4. 교사들에게 배포 (USB/이메일/네트워크)
5. 교사가 JSON 파일 불러오기
6. 자동으로 공결 표시
```

## 기술 스택

- **HTML5**: 단일 파일 구조
- **JavaScript**: Vanilla JS (프레임워크 없음)
- **CSS3**: 완전한 v1.0 디자인 복제
- **localStorage**: 브라우저 저장소
- **CSV**: 데이터 제출 형식

## 제한사항

- ❌ **실시간 동기화 없음**: 각 교사가 독립 작업
- ❌ **중앙 통계 자동화 없음**: 담당자가 CSV 수집 필요
- ⚠️ **브라우저 데이터 삭제 주의**: localStorage 삭제 시 데이터 손실
