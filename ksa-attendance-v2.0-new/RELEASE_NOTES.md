## 🏗️ 기술 스택

### Frontend
- **React 18**: UI 프레임워크
- **Vite 7**: 빌드 도구
- **Inline Bundle**: 단일 HTML로 패키징

### Data Layer
- **localStorage**: 브라우저 저장소
- **JSON**: 데이터 형식
- **CSV**: 내보내기 형식

### 호환성
- Chrome 90+, Edge 90+, Firefox 88+, Safari 14+
- 모바일 브라우저 (iOS Safari, Android Chrome)
- localStorage 지원 브라우저 (거의 모든 최신 브라우저)

## 🚀 배포 방법

### 교사에게 배포
```bash
# 1. 파일 복사
cp attendance.html /공유폴더/

# 2. 이메일 첨부
첨부 파일: attendance.html (376KB)
제목: [면학시스템 v2.0] 오프라인 출석 체크 앱

# 3. USB 복사
attendance.html을 USB에 복사 → 교사 PC로 전달
```

### 사용 시작
1. `attendance.html` 더블클릭
2. 브라우저에서 자동 실행
3. 출석 체크 시작!

## 📝 알려진 제한사항

1. **localStorage 용량 제한**
   - 일반적으로 5-10MB
   - 약 25,000건의 출석 기록 저장 가능
   - 1개월 사용 시 약 500KB 사용

2. **브라우저 종속성**
   - 다른 브라우저 = 다른 저장소
   - 브라우저 데이터 삭제 시 출석 데이터도 삭제

3. **동시 편집 불가**
   - 여러 교사가 동시에 같은 데이터 편집 불가
   - 각자 독립적으로 작업 → CSV로 제출

4. **실시간 통계 없음**
   - 중앙 서버 없어서 전체 통계 자동 집계 불가
   - 담당자가 CSV 수집하여 Excel로 통계 작성
