## ❓ 자주 묻는 질문

### Q1: 여전히 빈 화면이 나와요
**A:** 
1. **브라우저 캐시 삭제**
   - Chrome: Ctrl + Shift + Delete
   - 캐시 이미지 및 파일 삭제
2. **강력 새로고침**
   - Windows: Ctrl + F5
   - Mac: Cmd + Shift + R
3. **다른 브라우저로 시도**
   - Chrome, Firefox, Safari 등

### Q2: 파일을 어떻게 선택하나요?
**A:**
1. `deploy_package` 폴더 열기
2. **Ctrl + A** (Windows) 또는 **Cmd + A** (Mac)
3. 모든 파일이 선택됨
4. 선택된 파일들을 드래그

### Q3: 드롭 영역이 안 보여요
**A:**
1. "Deploys" 탭이 맞는지 확인
2. 화면을 **아래로 스크롤**
3. "Need to update your site?" 텍스트 찾기

### Q4: 업로드가 안 돼요
**A:**
1. 인터넷 연결 확인
2. 파일 크기 확인 (420KB 정도)
3. 브라우저 팝업 차단 해제
4. 다른 브라우저로 시도

### Q5: 출석 저장이 안 돼요
**A:**
현재는 **프론트엔드만** 배포된 상태입니다.
출석 저장 기능을 사용하려면:
- 백엔드 서버 설정 필요
- `DEPLOYMENT_GUIDE.md` 참고
- Netlify Functions 설정 (추천)
