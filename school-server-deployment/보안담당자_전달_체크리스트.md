## ✅ 시스템 특징 요약

### 개인정보 보호
```
✅ 모든 데이터가 학교 서버 내부에만 저장
✅ 외부 클라우드/AI 서비스 사용 안 함
✅ 외부 API 호출 없음
✅ 학생 민감정보 수집 안 함 (학번, 이름, 학년만)
```

### 보안 특징
```
✅ 비밀번호 기반 인증
✅ 학교 내부망에서만 접근 (설정 가능)
✅ SQL Injection 위험 없음 (DB 미사용)
✅ 일반 웹 취약점 점검 대상
```

### 시스템 구조
```
교사 디바이스 (브라우저)
    ↓ HTTP/HTTPS
학교 내부 서버
    ├─ Frontend (React.js)
    ├─ Backend (Node.js)
    └─ Data Files (JSON, 로컬 저장)
```

## 💻 필요한 서버 사양

### 최소 사양
```
OS: Windows 10/11 또는 Ubuntu 20.04+
CPU: 듀얼코어 2GHz
RAM: 4GB
Storage: 20GB 여유 공간
Network: 학교 내부망 연결
```

### 소프트웨어
```
Node.js v18 이상 (무료, 오픈소스)
```

### 네트워크
```
포트: 80 (HTTP) 또는 443 (HTTPS)
      3001 (Backend API)
      5173 (개발 모드, 선택)
```

## 📋 협조 요청 사항

### 1. 보안 검토 (1-2시간)
```
□ SECURITY_GUIDE.md 검토
□ 시스템 아키텍처 확인
□ 취약점 체크리스트 검토
□ 데이터 저장 위치 확인
□ 승인 여부 결정
```

### 2. 서버 준비 (승인 후)
```
□ 서버 컴퓨터 준비
□ OS 설치 및 보안 패치
□ Node.js 설치
□ 방화벽 설정
□ 고정 IP 또는 도메인 설정
```

### 3. 시스템 설치 (30분-1시간)
```
□ 파일 압축 해제
□ 의존성 패키지 설치 (npm install)
□ 환경 설정 (IP 주소 등)
□ 서비스 실행 및 자동 시작 설정
```

### 4. 테스트 및 검증 (30분)
```
□ 로컬 접속 테스트
□ 다른 컴퓨터에서 접속 테스트
□ 스마트폰에서 접속 테스트
□ 출석 체크 기능 테스트
□ 데이터 저장 확인
```
