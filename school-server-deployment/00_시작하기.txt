   → 협조 요청 사항, 승인 체크리스트

3순위 📖 README.md
   → 전체 설치 및 운영 가이드

   → 파일 구성 및 각 파일 역할 설명

  ⚡ 빠른 시작 (테스트용)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Node.js 설치 (https://nodejs.org - LTS 버전)

2. 압축 해제
   Windows: C:\attendance-system
   Linux: /opt/attendance-system

3. 의존성 설치 (5-10분)
   cd backend && npm install
   cd ../frontend && npm install

4. 실행
   백엔드: cd backend && node server.js
   프론트엔드: cd frontend && npm run dev -- --host 0.0.0.0

5. 접속
   http://localhost:5173
   비밀번호: ksa2025

자세한 가이드: docs/QUICK_START.md

네트워크:

- 포트: 80, 443, 3001, 5173
